# NextDNS Provider

The NextDNS provider lets you declaratively manage the configuration of
[NextDNS](https://nextdns.io/) profiles: security, privacy, parental control,
settings, allowlist, denylist and rewrites.

This is AeroNet's `aeronet-wireless-broadband-llc/nextdns` fork of
[`LukeEvansTech/nextdns`](https://github.com/LukeEvansTech/terraform-provider-nextdns),
itself a fork of [`amalucelli/nextdns`](https://github.com/amalucelli/terraform-provider-nextdns).
It adds the fourteen profile switches the upstream provider cannot manage
(twelve security switches, `privacy.rotatingAdDomains` and `settings.bav`)
and keeps the upstream schema otherwise unchanged, so an existing state
moves across with `state replace-provider` and no resource changes.

## Installation

Published on the OpenTofu registry as `aeronet-wireless-broadband-llc/nextdns`
from this repository's signed GitHub Releases; no CLI configuration is needed.

## Example Usage

```terraform
terraform {
  required_providers {
    nextdns = {
      source  = "aeronet-wireless-broadband-llc/nextdns"
      version = "~> 0.7"
    }
  }
}

# The API key can also come from the NEXTDNS_API_KEY environment variable.
provider "nextdns" {
  api_key = var.nextdns_api_key
}
```

## Destroy behaviour

Destroying a profile-section resource (`nextdns_security`, `nextdns_privacy`,
`nextdns_parental_control`, `nextdns_settings`, `nextdns_allowlist`,
`nextdns_denylist`, `nextdns_rewrite`) only removes it from state and leaves
the live profile unchanged, unless `reset_on_destroy = true` was applied
first. Destroying `nextdns_profile` fails unless `deletion_protection = false`
was applied first. Every resource imports by profile ID.

## Authentication

An API key is required. Find it on the
[NextDNS account page](https://my.nextdns.io/account). Pass it as `api_key`
or set the `NEXTDNS_API_KEY` environment variable.

## Schema

### Optional

- `api_key` (String, Sensitive) NextDNS API Key. Falls back to the `NEXTDNS_API_KEY` environment variable.
- `base_url` (String) Base URL of the NextDNS API. Defaults to `https://api.nextdns.io/`; falls back to the `NEXTDNS_BASE_URL` environment variable. Only useful for testing against a stub: the API key is sent to this URL, so only `https://api.nextdns.io/` and loopback URLs (`http://127.0.0.1:<port>/`, `http://localhost:<port>/`) are accepted, and anything else is a configuration error.
